# LEEME — Capturas pendientes para ltq2

> **Workflow:** Para cada captura, hacé la captura de pantalla / frame del video,
> guardala en `capturas/` con el nombre indicado, y anotá el link de YouTube con timestamp.
> Cuando esté listo, pasámelo y lo incorporo con la sintaxis correcta de Quarto.

---

## Cómo completar

Para cada captura indicá:

- **Link YouTube:** la URL completa incluyendo `&t=XYs` para el timestamp exacto
- **Estado:** ✅ lista / ⏳ pendiente / ❌ no disponible
- **Notas:** cualquier cambio respecto de lo planeado
